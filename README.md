# 坦克大战（Battle City）

一个使用纯 HTML + Canvas + JavaScript 实现的经典「坦克大战」小游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 玩法

- 控制你的坦克，摧毁每一关的所有敌方坦克
- 保护屏幕底部的基地（老鹰），基地被摧毁则游戏结束
- 拾取敌人掉落的道具获得强化

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `空格` / `J` | 射击（可按住连发） |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |
| `Enter` / 点击画面 | 开始 / 重开 |

## 道具

- ★ 火力升级（更快子弹、双发、可击穿钢墙）
- ⬤ 护盾（短暂无敌）
- ♥ 额外生命
- ✸ 手雷（消灭场上所有敌人）
- ▲ 铁锹（临时加固基地）

## 运行

直接用浏览器打开 `index.html`，或启动任意静态服务器：

```bash
# 使用 Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```
